# Operational details fixed before inference

The week starts at campaign launch. At each new confirmatory group, reserve the slowest pilot per-item time for the root and every earned or proposed endpoint, including token-matched endpoints. Add the projected search time for that group. Attempt the first primary pair even if the estimate is pessimistic. Before further groups, if their search and earned scoring no longer fit, write the time-only stopping inputs and jointly freeze the completed configurations. Keep incomplete coverage descriptive. These rules clarify the timing-only choice in the [original registration](preregistration.md).

One scheduled validation count allows one expansion window. An invalid edit consumes that window and its model tokens. Fallback attempts consume time and a common per-run allowance of one additional selector execution per validation-budget unit. Following exhaustion or loss of the worker, the harness can execute the known uniform root draw on the same random seed. Every attempt is retained. The final validation budget continues to count observed scientific outcomes. Model service errors retry the interrupted logical event, preserving the original error in the local ledger.

The broker shares memoized requests within the relevant compartment. The fixed reader can reuse an identical request across compartments. Complete messages, decoding options including seed, backend version, model digest and compartment contribute to the key. Identical seeded editor requests can also hit the memo. Successful uncached service duration includes backend overhead; failed attempt counts are separate. A fork inherits logical prefix tokens and incurs only its new physical calls. The public explorer updates at published milestones. Local observations refresh on each archived validation or expansion.
